# Texture attribution

Planet and star photographs in this folder are 2048×1024 equirectangular maps published by [Solar System Scope](https://www.solarsystemscope.com/textures/) under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). They are based on NASA imagery. The ring map is their Saturn ring strip with an alpha channel (2048×125).

| File | Body |
| --- | --- |
| `earth-day.jpg` | Earth daylight |
| `earth-clouds.jpg` | Earth clouds |
| `mars.jpg` | Mars |
| `jupiter.jpg` | Jupiter |
| `sun.jpg` | Sun |
| `saturn-ring.png` | Saturn rings |

Credit: Solar System Scope, CC BY 4.0.

`earth-normal.jpg` and `earth-spec.jpg` are the NASA-derived normal and specular maps shipped with the three.js examples (`examples/textures/planets`). The three.js project is MIT licensed. The underlying imagery is NASA.

The nebula, galaxies, star glow, and globular clusters are original shaders in this preview. They are not photographs.
