Privacy policy

Last updated 1 October 2026

This policy describes Clipped Yt Publish (Google Cloud project Clipper), a private tool run by Tom Gray. It is used only by Tom to upload YouTube Shorts and post comments on his own channel, Attention Well Spent, through the YouTube Data API.

Who runs it

Tom Gray
info@tomgray.co.uk

What the app accesses

The app only accesses the YouTube account of the person who signs in. That person is Tom. It uses that access to upload videos and post comments on that channel. It does not access anyone else's account.

How tokens are stored

OAuth tokens are stored privately on Tom's own machine. They are never shared or sold.

Other people and site visitors

No data is collected from other people, or from visitors to this website, via this app.

Google user data

Use of Google user data complies with the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

You can revoke this app's access at any time from your Google Account permissions.
